# Original source reference

The thesis cites the public GitHub repository: https://github.com/mysuachua/Luanvan

Original `handsignature_v7.py`: https://github.com/mysuachua/Luanvan/blob/main/handsignature_v7.py

The file performs webcam capture, MediaPipe landmark detection, finger-to-digit mapping, a ten-frame recognition average, three-digit serial commands, and `1111` / `1110` feedback handling. It is **not copied into this package** because no explicit open-source license was established for this repository. Keep the source attribution intact.
